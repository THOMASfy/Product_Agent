# S43 产品管理平台对接技能

## 用途
对接产品管理平台，读取/回写需求与缺陷的结构化数据。

> 说明：技能定义为「产品管理平台对接」，具体平台作为**连接器配置**注入（评审 R-07）。

## 依赖库
- 数据库（需求状态机、缺陷状态）

## 方法
1. **读取**：按筛选条件拉取需求/缺陷及其状态。
2. **状态映射**：平台状态 → 内部状态机。
3. **增量同步**：基于更新时间做增量。
4. **回写**：按需更新状态（如评审通过）。

## 输出
- 需求/缺陷数据表（含状态）
- 流转/状态变更摘要

## 约束
- 写操作须有明确授权与审计记录。
- 状态映射规则须显式声明。
