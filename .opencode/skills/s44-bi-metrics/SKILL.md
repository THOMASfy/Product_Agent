# S44 BI 指标调取技能

## 用途
从 BI 平台拉取指标并解读变化。

> 说明：技能定义为「BI 指标调取」，FineBI 等作为**连接器配置**注入（评审 R-07）。

## 依赖库
- 数据库（指标数据、口径字典）

## 方法
1. **取数**：按指标口径字典拉取目标指标。
2. **对比**：环比/同比，拆分结构。
3. **归因**：定位异常与驱动因素。
4. **呈现**：指标表 + 一句话解读。

## 输出
- 指标表（含口径、时点）
- 环比/同比解读与异常点

## 约束
- 指标口径须统一（口径字典）；标注数据时点。
- 业绩/薪酬等敏感数据仅输出聚合值（R-08）。
