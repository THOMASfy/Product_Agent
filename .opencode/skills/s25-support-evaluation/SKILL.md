# S25 产品支持评价技能

## 用途
量化评估产品支持的响应质量与用户满意度。

## 依赖库
- 数据库（工单系统，敏感字段脱敏）

## 方法
1. **取数**：工单量、响应时长、解决时长、满意度（归一化）。
2. **算指标**：首响时长、一次解决率、满意度、积压率。
3. **归因**：识别高频问题与短板环节。
4. **建议**：SLA 调整与知识库补充。

## 输出
- 支持质量指标表
- 高频问题清单
- 改进建议

## 约束
- 工单敏感字段必须脱敏后使用。
- 满意度口径须归一化并标注。
