# S41 协作文档解读技能

## 用途
把协作文档（飞书文档、进程信息）解析成结构化要点，供各 Agent 使用。

> 说明：技能语义与连接器分离——「协作文档解读」为技能定义，飞书/钉钉作为**连接器配置**注入（评审 R-07）。

## 依赖库
- 知识库（文档入池后的结构化条目）

## 方法
1. **识别类型**：需求、纪要、审批、客户往来。
2. **抽取**：实体（人/时间/诉求/结论/待办）。
3. **结构化**：输出要点与分类标签。
4. **入池**：交由 S26 知识管理沉淀（如需要）。

## 输出
- 结构化要点（主题/结论/待办/相关人）
- 分类标签

## 约束
- 敏感信息脱敏后处理。
- 不改写原意；不确定处标注。
