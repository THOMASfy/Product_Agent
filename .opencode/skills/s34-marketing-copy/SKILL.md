# S34 推广文案技能

## 用途
按渠道产出转化导向的推广文案。

## 依赖库
- 知识库（产品卖点、用户画像、渠道规范）

## 方法
1. **渠道画像**：不同渠道（社群/搜索/信息流/私域）表达差异。
2. **结构**：钩子 → 价值 → 证据 → CTA。
3. **多版本**：每个渠道产出 2–3 个版本做 A/B。
4. **合规**：避免绝对化用语与虚假宣传。

## 输出
- 多渠道文案（每渠道 2–3 版）
- 传播素材要点与 CTA

## 约束
- 不做虚假或绝对化承诺；标注素材出处。
- 对外发布前需人工审批（R-11）。
