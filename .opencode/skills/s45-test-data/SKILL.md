# S45 测试反馈数据读取技能

## 用途
读取测试执行与缺陷数据，支撑质量门禁判定。

> 说明：技能定义为「测试反馈数据读取」，具体测试系统作为**连接器配置**注入（评审 R-07）。

## 依赖库
- 数据库（测试用例、执行结果、缺陷）

## 方法
1. **取数**：用例执行率、通过率、缺陷分布。
2. **收敛分析**：缺陷新增/修复趋势、遗留等级。
3. **门禁判定**：给出发布质量门禁结论。
4. **风险提示**：列出必须修复项。

## 输出
- 测试执行与缺陷表
- 缺陷收敛趋势
- 门禁判定与必须修复项

## 约束
- 判定阈值须显式声明；标注数据口径。
- 不代替 A22 做业务判断。
