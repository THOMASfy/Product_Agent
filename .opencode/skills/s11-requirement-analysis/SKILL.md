# S11 需求分析技能

## 用途
把零散、口语化的原始需求，转成**结构化、可验收**的需求池。

## 依赖库
- 知识库（产品知识文档、飞书进程信息、经验条目）
- skills库（调用统计）

## 方法
1. **抽取**：从文档/进程信息中收集原始诉求。
2. **清洗**：去重、合并同类，剔除纯方案描述。
3. **分类**：功能 / 非功能；区分「需求(问题)」与「方案(功能)」。
4. **优先级**：MoSCoW + 价值/成本打分。
5. **验收**：为每条需求写可测试的验收标准。

## 输出
- 需求池表：`ID – 需求 – 类型 – 优先级 – 依据 – 验收标准`
- 未决问题清单（信息缺口）

## 约束
- 不设计解决方案、不估成本（交下游）。
- 信息不足标注`【假设】`与置信度，不编造。
