# S12 竞品分析技能

## 用途
系统化对比竞品，识别我方的差异化机会与威胁。

## 依赖库
- 知识库（竞品资料、行业报告）

## 方法
1. **定义竞品集**：直接竞品 / 间接竞品 / 潜在进入者。
2. **定义维度**：定位、目标用户、功能、价格、渠道、优势、弱点。
3. **构建矩阵**：逐项打分/标注。
4. **机会识别**：找出对手未覆盖或做得差的点。
5. **策略建议**：给出差异化与应对方向。

## 输出
- 竞品对比矩阵
- 差异化机会清单 + 威胁清单
- 策略建议（各 2–3 条）

## 约束
- 标注数据来源与时点；不编造竞品数据。
- 不涉及产品设计与定价决策（交下游）。
