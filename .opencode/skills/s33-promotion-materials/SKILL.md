# S33 产品宣传材料技能

## 用途
产出用于获客与传播的宣传物料要点。

## 依赖库
- 知识库（产品资料、目标画像）

## 方法
1. **受众**：明确渠道与受众。
2. **结构**：痛点 → 方案 → 价值 → 行动召唤(CTA)。
3. **素材**：宣传册/介绍页的标题、段落与要点。
4. **渠道适配**：按渠道调整表达侧重。

## 输出
- 宣传素材要点（标题/正文/CTA）
- 渠道适配说明

## 约束
- 不夸大、不做虚假承诺。
- 对外发布前需人工审批（R-11）。
