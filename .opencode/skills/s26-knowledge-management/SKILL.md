# S26 知识管理技能

## 用途
把组织知识沉淀为可检索、可治理的资产。

## 依赖库
- 知识库

## 方法
1. **采集**：从文档/会议/经验中抽取知识。
2. **去重**：相似条目合并。
3. **标签化**：主题标签 + owner + 有效期 + 来源。
4. **治理**：经验类须经评审后方可入库（评审 R-05）。
5. **检索分发**：按需检索并分发到相关任务。

## 输出
- 知识条目（含标签/owner/有效期）
- 检索结果
- 失效复核清单

## 约束
- 经验类知识未经评审不得采信；标注来源。
- 敏感信息须脱敏或分级。
