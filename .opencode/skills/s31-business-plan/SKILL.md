# S31 商业计划书撰写技能

## 用途
产出正式、逻辑闭环的商业计划书/商务方案。

## 依赖库
- 知识库（市场、竞品、产品资料）

## 方法
1. **结构**：市场分析 → 产品服务 → 商业模式 → 财务计划 → 风险。
2. **论证**：每部分给数据支撑与逻辑链，不堆概念。
3. **财务**：收入/成本/毛利/现金流/盈亏平衡，用区间。
4. **风险**：列出关键风险与应对。

## 输出
- 商业计划书正文（章节化）
- 财务测算表（区间）
- 风险与待确认清单

## 约束
- 不编造融资结果、签约结果、真实财务事实。
- 假设一律标注`【假设】`/`【待确认】`。
- 报价与对外承诺类内容需人工审批（R-11）。
